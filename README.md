# Core-Breach-Zero

Menu prototype for a tower defense game. Run `npm install` and `npm start`, then
open `http://localhost:3000`. Register or log in with a commander account before
using the four deployment bays. Accounts are stored in `accounts.json` beside the
server; passcodes are stored as salted hashes. A bay host can choose a map and
set squad size to 2-4 commanders. Gameplay is not implemented yet. Set `PORT` to
choose a different listening port.
